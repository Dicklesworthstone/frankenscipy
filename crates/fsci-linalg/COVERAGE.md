do not need fsci counterparts (`special_matrices`, `LinAlgError`,
`LinAlgWarning`, etc. — fsci uses its own `LinalgError` enum and folds
the special_matrices submodule into the top-level crate).

functions that are NOT in scipy.linalg — see "fsci-only extras" below.

## How to refresh this audit

```bash
# (1) capture scipy surface (matches version in the relevant venv)
python3 -c 'import scipy.linalg as la; import inspect; \
  [print(n) for n in sorted(la.__all__) \
   if callable(getattr(la,n)) and not inspect.isclass(getattr(la,n))]'

# (2) capture fsci-linalg surface
grep -E "^pub fn [a-z_]+" crates/fsci-linalg/src/lib.rs \
  | sed 's/^pub fn //; s/(.*//; s/<.*//' | sort -u

# (3) re-run the diff (see frankenscipy-fgxx for the python script).
```
